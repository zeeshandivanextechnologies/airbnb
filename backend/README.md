# Airbnb Clone Backend

Node.js + Express + PostgreSQL API server.

## Setup Instructions

1. Go to backend directory:
   `ash
   cd backend
   `

2. Install dependencies:
   `ash
   npm install
   `

3. Configure .env file with your PostgreSQL credentials:
   `env
   PORT=5000
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=airbnb_db
   DB_USER=postgres
   DB_PASSWORD=your_password
   `

4. Run development server:
   `ash
   npm run dev
   `
